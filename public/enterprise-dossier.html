2. Full-Stack Distributed System Architecture

Client Layer (Front-End)

  • React 19 & TypeScript: Type-safe reactive component tree with sub-millisecond state updates.
  • Incremental DOM Pagination: Initial mount locked to 12 cards with dynamic chunking, reducing mobile memory footprint.
  • Optimized Asset Handling: WebP imagery with native lazy loading, async decoding, and automated fallback routing.

Data Core & Serverless APIs

  • Supabase PostgreSQL: Relational database with typed schemas for products gearshop, quote_requests, product_requests, and leads.
  • Serverless Microservices: /api/send-email (Resend) and /api/meta-capi (Meta CAPI) with zero privileged tokens in client bundle.
  • Google Merchant Pipeline: Automated RSS 2.0 XML generator mapping 280 products with verified local assets.

3. 360° Technical SEO, GEO & AI Ingestion (AIO)

The platform implements an exhaustive four-tier organic discoverability engine:

  • Static Pre-rendering (SSG - 356 Sitemap URLs): Every product, brand, category, and Moroccan city hub receives a pre-compiled HTML instance for immediate crawler discovery.
  • Self-Referential Canonicals: Each indexable route receives a normalized self-referencing canonical URL under https://www.gearshop.ma/.
  • Schema.org v14.0 JSON-LD: Microdata covering Product, Offer (MAD currency), BreadcrumbList, and LocalBusiness.
  • Generative Engine Optimization (GEO): Dedicated /llms.txt and /llms-full.txt (375 KB) endpoints enabling ChatGPT, Claude, Perplexity, and Gemini to ingest specifications accurately.
