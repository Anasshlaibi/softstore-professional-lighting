2. Full-Stack Distributed System Architecture

Client Layer (Front-End)

  • React 19 & TypeScript: Type-safe reactive component tree with sub-millisecond state updates.
  • Tailwind CSS Design System: Bespoke dark/light glassmorphism tokens, zero runtime style overhead.
  • Progressive DOM Pagination: Initial mount locked to 12 cards with dynamic chunking, preventing mobile memory exhaustion.

Data Core & Microservices

  • Supabase PostgreSQL 15: High-concurrency relational data store with Row-Level Security (RLS).
  • Vercel Serverless Edge: Zero-trust API endpoints for quotation generation (Resend) and Meta CAPI.
  • Multi-Channel Syndication: Native RSS 2.0 XML generator for Google Merchant Center.

3. 360° Technical SEO, GEO & AI Ingestion (AIO)

The platform implements an exhaustive four-tier organic discoverability engine:

  • Static Site Generation (SSG - 358 Pages): Every product, brand, category, and Moroccan city hub has a dedicated pre-compiled HTML snapshot for instant Googlebot indexing.
  • Schema.org v14.0 JSON-LD: Deep microdata covering Product, Offer (MAD currency), BreadcrumbList, and LocalBusiness.
  • Generative Engine Optimization (GEO): Dedicated /llms.txt and /llms-full.txt endpoints enabling ChatGPT Search, Claude, Perplexity, and Gemini to accurately ingest specs and recommend products.
  • Google Merchant Center Sync: Automated daily scheduled fetch at https://www.gearshop.ma/google-merchant-feed.xml with 100% verified WebP assets.
